# Screens

Product screens that decide which components the design system builds (`_workflow/tasks/2026-11-17-screen-first-plan.md`).

One folder per flow, kebab-case: `_workflow/screens/<flow>/` (for example `sign-in`, `attendance-dashboard`).

| File | Who | What |
|---|---|---|
| `<flow>/screen-<n>-<platform>.png` | Hassan | Screen image (optional when a Figma link is given) |
| `<flow>/analysis.md` | Claude | Figma link, element → component map, gap list, Hassan's approval |
| `component-inventory.md` | Claude | All components, which screens need them, build status |
